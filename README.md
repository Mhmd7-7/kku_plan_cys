# خطة الأمن السيبراني – جامعة الملك خالد

موقع ثابت لعرض خطة بكالوريوس **الأمن السيبراني – مجال التحقيق الجنائي الرقمي**، مع الحفاظ على تصميم الموقع العربي واتجاه RTL.

## بيانات الخطة

- الكلية: علوم الحاسب.
- القسم: المعلوماتية وأنظمة الحاسب.
- التخصص: `010107`، المسار: `0101072`.
- الإصدار: 1، الفصل: 461، نوع الخطة: فرعي.
- الإجمالي: **134 ساعة** = 130 إجبارية + ساعتان اختياريتان + ساعتان حرتان.
- 41 مقررًا إجباريًا على ثمانية مستويات، وساعاتها: **15، 15، 18، 21، 18، 16، 19، 8**.
- المجموعة الاختيارية تعرض عشرة بدائل؛ المطلوب اختيار مقرر واحد بساعتين، وليس احتساب جميع البدائل ضمن إجمالي الخطة.

المصدر: مستند خطة CYS المرفق، مع مطابقة المقررات مع تصدير الخطة المرفق. المتطلبات السابقة مأخوذة من المستند، وليست من خطة علوم الحاسب القديمة.

## التشغيل

افتح [الموقع](<index.html>) مباشرة في المتصفح. لا يحتاج الموقع إلى تثبيت حزم أو بناء أو خادم. يتطلب الخط الخارجي اتصالًا بالإنترنت، ويُستخدم خط بديل عند عدم توفره.

## استيراد التقدم الدراسي

الحالة الافتراضية لجميع المقررات هي **غير مكتمل**، دون تضمين تقدم شخصي تلقائيًا.

افتح لوحة «بيانات التقدم الدراسي (JSON)»، والصق إحدى الصيغ التالية ثم اضغط «تطبيق الحالة من JSON»:

### مصفوفة المستويات

```json
[
  {
    "levelIndex": 0,
    "courses": [
      { "code": "0522نجل-5", "status": "TAKEN" },
      { "code": "0291تطوع-2", "status": "TAKEN_NOW" }
    ]
  }
]
```

### قائمة مقررات مباشرة

```json
[
  { "courseCode": "1300أمن-3", "status": "TAKEN" },
  { "code": "2412أمن-4", "status": "NOT_TAKEN" }
]
```

الحالات المقبولة: `TAKEN` و`TAKEN_NOW` و`NOT_TAKEN`. يُقبل `code` أو `courseCode` في الصيغتين. يتم تجاهل السجلات غير الصالحة والمقررات خارج الخطة مع عرض تنبيه بعددها. عند نجاح الاستيراد، تعود المقررات غير المذكورة إلى حالة «غير مكتمل». الإدخال غير الصالح لا يغيّر الحالة الحالية.

يدعم الموقع كذلك معامل الرابط `JsonC` الذي يحتوي على JSON مشفّر بصيغة Base64 باستخدام UTF-8؛ يجب ترميز قيمة المعامل عبر `encodeURIComponent` أو `URLSearchParams`.

الاستيراد يغيّر **الحالات فقط**، ولا يستبدل المقررات أو متطلباتها. لا تُحفظ الحالات بعد إغلاق الصفحة أو إعادة تحميلها، إلا بإعادة الاستيراد أو استخدام رابط `JsonC`.

## الاختبارات

باستخدام Node.js، من داخل مجلد المشروع:

```powershell
node --test --test-isolation=none tests/plan.test.cjs
```
